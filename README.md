## Fianchetto / Matugen

This config optionally loads `lua/config/fianchetto.lua`, generated by Fianchetto's **Appearance → Application themes → Neovim** integration. If the file is absent, the original palette in `lua/config/palette.lua` is used unchanged. Wallpaper palette updates refresh highlights, bufferline, and lualine in running Neovim sessions.
